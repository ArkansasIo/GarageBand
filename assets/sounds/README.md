# StudioWave Sound Asset Library

21 original procedural WAV files for the StudioWave browser DAW. These are generated synthetic samples, not copied recordings or proprietary GarageBand assets.

## Format
- RIFF/WAVE PCM
- 22,050 Hz sample rate
- Mono, signed 16-bit samples
- Categories: drums, bass, synths, keys, effects and utility

## Integration
The Sound Browser loads the WAVs as Web Audio buffers, provides a preview button and can add a sample as an audio track. Kick, snare and closed hi-hat steps use the matching sample when loaded, with synthesized playback as fallback.

See [manifest.json](./manifest.json) for the inventory.

## Provenance
These files were procedurally synthesized for this repository and contain no third-party samples. They are provided for use within the StudioWave project. No proprietary GarageBand sound assets are included.
