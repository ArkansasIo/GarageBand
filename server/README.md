# StudioWave API

TypeScript REST API for accounts and cloud project storage.

- Install dependencies from the repository root with `npm install`.
- Configure `.env` using `.env.example`.
- Initialize MySQL with `db/schema.sql`.
- Development: `npm run dev:api`.
- Type-check: `npm run typecheck`.
- Compile: `npm run build:api`.

See [API and database setup](../docs/API_AND_DATABASE.md).
